What is the Blackbox Series

Hardware Meets Code

Each Blackbox pairs a physical circuit with programmable logic. Wire it, flash it, and watch your reasoning come alive on real signals.

Layered Challenges

Puzzles stack from single gates to full state machines. Solve one layer to unlock the next — no hand-holding, just clues in the signals.

Learn by Doing

Pick up electronics fundamentals and embedded programming through play: bits, timing, registers, and assembly — one tick at a time.

See the Signals

Live waveform scopes and I/O line viewers turn abstract logic into something you can watch, debug, and finally understand.

Tiny, Honest ISA

A minimal 1-bit instruction set keeps everything transparent. No magic — just IN, XOR, OUT, TICK, and your own ideas.

Fully Offline

Every tool is a single self-contained file. No installs, no accounts, no cloud — open it in a browser and start hacking.
